# PiTouch — телефон как тачпад и клавиатура для Raspberry Pi

Android-приложение превращает телефон в беспроводной тачпад и клавиатуру для Raspberry Pi по Bluetooth.
Рассчитано на Android 9+ (Honor 20) и Raspberry Pi 3B+ с Raspberry Pi OS.

## Возможности

- **Тачпад:** курсор с ускорением, тап — клик, тап двумя пальцами — ПКМ, тремя — СКМ,
  тап + удержание — перетаскивание, прокрутка двумя пальцами (вертикальная и горизонтальная).
- **Кнопки ЛКМ / СКМ / ПКМ** — можно держать ЛКМ и водить пальцем по тачпаду.
- **Гироскоп («аэромышь»):** держите телефон горизонтально, верхом к монитору,
  и поворачивайте/наклоняйте его.
- **Клавиатура:** обычная клавиатура телефона (в том числе голосовой ввод) + панель:
  Esc, Tab, Ctrl, Alt, Shift, Win, стрелки, Home/End, Del, ⌫, ⏎, F1–F12, PgUp/PgDn, Ins, PrtSc,
  быстрые сочетания (Ctrl+C/V/X/Z/A/S, Alt+Tab, Alt+F4, Ctrl+Alt+T — терминал).
- **Кириллица:** приложение само переключает раскладку на Pi (Alt+Shift по умолчанию),
  когда вы печатаете русские или английские буквы.
- Залипающие модификаторы: одно нажатие — для следующей клавиши (жёлтая),
  второе — фиксация (зелёная), третье — выключить.
- Автоподключение к последнему Pi, экран не гаснет, пока приложение открыто.

## Установка приложения

1. Откройте на телефоне страницу релиза **latest** этого репозитория
   (Releases → latest) и скачайте `PiTouch.apk`.
2. Разрешите установку из неизвестных источников и установите.
   Новые сборки ставятся поверх старой без удаления.

## Два режима подключения

| | Bluetooth-клавиатура (по умолчанию) | Сервер на Pi (запасной) |
|---|---|---|
| Что ставить на Pi | ничего | `pi/install.sh` |
| Как работает | телефон притворяется обычной BT-клавиатурой и мышью | приложение шлёт команды программе на Pi |
| Где работает | везде: рабочий стол, консоль, экран входа | после загрузки системы |

Начните с первого. Если телефон его не поддерживает (приложение покажет сообщение) —
переключитесь на второй в настройках (⚙).

### Режим «Bluetooth-клавиатура»

1. Если телефон уже был сопряжён с Pi — удалите сопряжение **на обоих** устройствах
   (иначе Pi не узнает, что телефон теперь клавиатура).
2. Откройте PiTouch → ⚙ → «Сделать телефон видимым».
3. На Pi: значок Bluetooth → **Add Device…** → выберите телефон → подтвердите код на обоих.
   Или в терминале:
   ```
   bluetoothctl
   scan on            # дождитесь появления телефона, запомните его MAC
   pair XX:XX:XX:XX:XX:XX
   trust XX:XX:XX:XX:XX:XX
   connect XX:XX:XX:XX:XX:XX
   ```
4. Статус в приложении станет зелёным «Подключено». Дальше приложение подключается само.

### Режим «Сервер на Pi»

На Pi:
```
git clone https://github.com/nervotrepka/k.git pitouch
cd pitouch/pi
./install.sh
```
(или скачайте `pitouch-pi.tar.gz` из релиза, распакуйте и запустите `pi/install.sh`).

Затем сопрягите телефон с Pi обычным способом (Pi → Add Device или настройки Bluetooth телефона),
в PiTouch: ⚙ → режим «Сервер на Pi» → «Выбрать Raspberry Pi».

Проверка: `sudo systemctl status pitouch`, логи: `journalctl -u pitouch -f`.
Удаление: `pi/uninstall.sh`.

## Русский язык

Bluetooth-клавиатура передаёт не буквы, а номера клавиш — буквы получаются из раскладки на Pi.
Поэтому на Pi должны быть включены раскладки **us,ru** с тем же сочетанием переключения, что в приложении:

```
cd pitouch/pi
./setup-keyboard-layout.sh alt_shift     # или ctrl_shift / win_space / caps
sudo reboot
```

Кнопка **EN/RU** в приложении показывает и переключает раскладку. Если индикатор разошёлся с Pi
(например, раскладку переключили с другой клавиатуры) — **долгое нажатие** на EN/RU исправит
индикатор, ничего не отправляя на Pi.

## Настройки (⚙)

Скорость и ускорение курсора, скорость прокрутки, чувствительность гироскопа,
естественная прокрутка, тап = клик, подсказки/автозамена клавиатуры телефона,
сочетание переключения раскладки.

## Если не работает

- **«Телефон не поддерживает режим Bluetooth-клавиатуры»** — используйте режим «Сервер на Pi».
- **Pi не видит телефон как клавиатуру** — удалите сопряжение на обоих устройствах и выполните его заново
  при открытом PiTouch в режиме «Bluetooth-клавиатура».
- **«Сервер на Pi не отвечает»** — `sudo systemctl restart pitouch`, проверьте `journalctl -u pitouch`.
- **Вместо русских букв латиница** — запустите `setup-keyboard-layout.sh` и перезагрузите Pi;
  проверьте, что сочетание в настройках приложения совпадает.

## Устройство проекта

- `app/` — Android-приложение (Kotlin, без сторонних библиотек, minSdk 28).
  - `hid/` — HID-дескриптор, раскладки EN/RU, логика набора текста.
  - `bt/` — режим Bluetooth HID (`BluetoothHidDevice`) и режим RFCOMM.
  - `ui/` — тачпад, гироскоп, перехват клавиатуры телефона.
- `pi/` — сервер для Pi (Python, BlueZ D-Bus + uinput), установщик, настройка раскладки.
- `.github/workflows/build.yml` — тесты, сборка APK и публикация релиза `latest` при каждом push.

Подпись APK: ключ `app/pitouch.keystore` (пароль `pitouch`) лежит в репозитории специально,
чтобы новые сборки ставились поверх старых. Для публикации в магазинах замените его.
