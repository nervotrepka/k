# PiTouch — телефон как тачпад и клавиатура для Raspberry Pi

Android-приложение превращает телефон в беспроводной тачпад, клавиатуру и пульт для Raspberry Pi,
ПК, планшета и телевизора Samsung.
Рассчитано на Android 9+ (Honor 20) и Raspberry Pi 3B+ с Raspberry Pi OS.

## Возможности

- **Несколько устройств:** Raspberry Pi, ПК с Windows, Android-планшет, Samsung TV и любые другие,
  которые понимают Bluetooth-клавиатуру. Переключение — кнопкой с названием устройства вверху.
- **Тачпад:** курсор с ускорением, тап — клик, тап двумя пальцами — ПКМ, тремя — СКМ,
  тап + удержание — перетаскивание, прокрутка двумя пальцами. Кнопки ЛКМ / СКМ / ПКМ.
- **Гироскоп («аэромышь»):** кнопка ◎; держите телефон горизонтально, верхом к экрану.
- **Клавиатура:** клавиатура телефона (кнопка ⌨, в том числе голосовой ввод) + панель:
  Esc, Tab, Ctrl, Alt, Shift, Win, стрелки, Home/End, Del, ⌫, ⏎, F1–F12, сочетания.
- **Пульт:** питание, источник, «Домой», меню, стрелки, OK, «Назад», громкость, каналы,
  перемотка, пауза, цифры, YouTube.
  - по **Wi-Fi** (Samsung, сетевой протокол ТВ) — работают все кнопки, включая питание и YouTube;
  - по **Bluetooth** — громкость, без звука, медиа, «Домой», «Назад», стрелки, OK, цифры.
- **Навигация по Android:** для устройства типа «Android-планшет» вкладка «Пульт» становится
  «Навигацией»: Назад, Домой, Недавние, Уведомления, Приложения, Поиск, стрелки + OK и Tab
  (перемещение выделения по интерфейсу), громкость, медиа, скриншот, экран вкл/выкл.
- **Дублирование набора:** над тачпадом показывается текст, который вы печатаете на устройстве.
- **Текст:** вкладка «Текст» — наберите текст на телефоне (с автозаменой, голосом, вставкой) и
  отправьте в поле ввода на устройстве. На ТВ по Wi-Fi текст уходит сразу целиком.
  Длинный текст печатается без потерь (с повтором при заторе Bluetooth), с индикатором и кнопкой «Стоп».
  Опция «Новая строка = Shift+Enter» — чтобы в мессенджерах многострочный текст не отправлялся по частям.
  Типографские символы (« » — … “ ”) заменяются на обычные.
- **Кириллица:** приложение само переключает раскладку на устройстве (для каждого устройства
  своё сочетание: Alt+Shift для Linux/Windows, Ctrl+Space для Android).
- **Работа в фоне:** связь не рвётся при сворачивании — в шторке висит уведомление PiTouch
  с кнопкой «Выход».
- **Адаптивный интерфейс:** подстраивается под половину экрана (разделённый экран),
  альбомную ориентацию и планшеты.

## Установка приложения

1. Откройте на телефоне страницу релиза **latest** этого репозитория
   (Releases → latest) и скачайте `PiTouch.apk`.
2. Разрешите установку из неизвестных источников и установите.
   Новые сборки ставятся поверх старой без удаления.

## Обновление с первой версии

В приложение добавлены медиа-кнопки (громкость и т.п.), из-за этого изменилось описание
Bluetooth-клавиатуры. **Удалите сопряжение телефона на Pi и выполните его заново**, иначе новые кнопки
работать не будут. Ваш Pi автоматически перенесётся в список устройств.

## Подключение других устройств

Порядок для любого устройства: удалите старое сопряжение (если было) → в PiTouch ⚙ →
«Сделать телефон видимым» → на устройстве добавьте телефон как Bluetooth-устройство:

- **Windows:** Параметры → Bluetooth и устройства → Добавить устройство → Bluetooth.
- **Android-планшет:** Настройки → Bluetooth → выбрать телефон. Для кириллицы на планшете:
  Настройки → Язык и ввод → Физическая клавиатура → добавить русскую раскладку
  (переключение Ctrl+Space).
- **Samsung TV:** Настройки → Общие → Диспетчер внешних устройств → Диспетчер устройств
  ввода → Bluetooth-устройства (название пунктов зависит от года).

После подключения устройство само появится в списке. Нажмите на название вверху →
«Изменить текущее» и выберите тип (от него зависят раскладка и пауза между клавишами).

### Wi-Fi пульт Samsung

1. Телефон и ТВ в одной Wi-Fi сети.
2. Название вверху → «Изменить текущее» (или «Добавить») → тип «Samsung TV» →
   «Найти телевизор в сети» (или введите IP: ТВ → Настройки → Общие → Сеть → Состояние сети).
3. Нажмите любую кнопку пульта — на ТВ появится запрос, нажмите «Разрешить».
4. Чтобы кнопка ⏻ включала ТВ из режима ожидания, на ТВ включите «Включение с мобильного»
   (Настройки → Общие → Сеть → Экспертные настройки). На старых ТВ включение по сети не работает.

Поддерживаются ТВ Samsung 2010–2014 и 2016+ годов. Модели 2015 года (серия **J**, например UE40J5200)
используют зашифрованный протокол — для них работает только Bluetooth-пульт.
Год можно узнать по букве после диагонали в модели ТВ: H — 2014, J — 2015, K — 2016, M — 2017, N/R/T/A… — новее.

## Два режима Bluetooth для Raspberry Pi

| | Bluetooth-клавиатура (по умолчанию) | Сервер на Pi (запасной) |
|---|---|---|
| Что ставить на Pi | ничего | `pi/install.sh` |
| Как работает | телефон притворяется обычной BT-клавиатурой и мышью | приложение шлёт команды программе на Pi |
| Где работает | везде: рабочий стол, консоль, экран входа | после загрузки системы |

Начните с первого. Если телефон его не поддерживает (приложение покажет сообщение) —
переключитесь на второй в настройках (⚙).

### Режим «Bluetooth-клавиатура»

1. Если телефон уже был сопряжён с Pi — удалите сопряжение **на обоих** устройствах
   (иначе Pi не узнает, что телефон теперь клавиатура).
2. Откройте PiTouch → ⚙ → «Сделать телефон видимым».
3. На Pi: значок Bluetooth → **Add Device…** → выберите телефон → подтвердите код на обоих.
   Или в терминале:
   ```
   bluetoothctl
   scan on            # дождитесь появления телефона, запомните его MAC
   pair XX:XX:XX:XX:XX:XX
   trust XX:XX:XX:XX:XX:XX
   connect XX:XX:XX:XX:XX:XX
   ```
4. Статус в приложении станет зелёным «Подключено». Дальше приложение подключается само.

### Режим «Сервер на Pi»

На Pi:
```
git clone https://github.com/nervotrepka/k.git pitouch
cd pitouch/pi
./install.sh
```
(или скачайте `pitouch-pi.tar.gz` из релиза, распакуйте и запустите `pi/install.sh`).

Затем сопрягите телефон с Pi обычным способом (Pi → Add Device или настройки Bluetooth телефона),
в PiTouch: ⚙ → режим «Сервер на Pi» → «Выбрать Raspberry Pi».

Проверка: `sudo systemctl status pitouch`, логи: `journalctl -u pitouch -f`.
Удаление: `pi/uninstall.sh`.

## Русский язык

Bluetooth-клавиатура передаёт не буквы, а номера клавиш — буквы получаются из раскладки на Pi.
Поэтому на Pi должны быть включены раскладки **us,ru** с тем же сочетанием переключения, что в приложении:

```
cd pitouch/pi
./setup-keyboard-layout.sh alt_shift     # или ctrl_shift / win_space / caps
sudo reboot
```

Кнопка **EN/RU** в приложении показывает и переключает раскладку. Если индикатор разошёлся с Pi
(например, раскладку переключили с другой клавиатуры) — **долгое нажатие** на EN/RU исправит
индикатор, ничего не отправляя на Pi.

## Настройки (⚙)

Скорость и ускорение курсора, скорость прокрутки, чувствительность гироскопа,
естественная прокрутка, тап = клик, подсказки/автозамена клавиатуры телефона,
сочетание переключения раскладки.

## Если не работает

- **Связь рвётся в фоне** — ⚙ → «Разрешить работу в фоне»; на Honor также: Настройки → Батарея →
  Запуск приложений → PiTouch → управлять вручную, включить все переключатели.
- **ТВ теряет буквы при отправке текста по Bluetooth** — увеличьте паузу между клавишами в настройках устройства.
- **«Телефон не поддерживает режим Bluetooth-клавиатуры»** — используйте режим «Сервер на Pi».
- **Pi не видит телефон как клавиатуру** — удалите сопряжение на обоих устройствах и выполните его заново
  при открытом PiTouch в режиме «Bluetooth-клавиатура».
- **«Сервер на Pi не отвечает»** — `sudo systemctl restart pitouch`, проверьте `journalctl -u pitouch`.
- **Вместо русских букв латиница** — запустите `setup-keyboard-layout.sh` и перезагрузите Pi;
  проверьте, что сочетание в настройках приложения совпадает.

## Устройство проекта

- `app/` — Android-приложение (Kotlin, без сторонних библиотек, minSdk 28).
  - `hid/` — HID-дескриптор, раскладки EN/RU, логика набора текста.
  - `bt/` — режим Bluetooth HID (`BluetoothHidDevice`) и режим RFCOMM.
  - `ui/` — тачпад, гироскоп, перехват клавиатуры телефона.
  - `tv/` — Wi-Fi пульт Samsung (WebSocket API и старый протокол порта 55000), поиск ТВ.
  - `devices/` — список устройств; `Core` + `ConnectionService` — связь, живущая в фоне.
- `pi/` — сервер для Pi (Python, BlueZ D-Bus + uinput), установщик, настройка раскладки.
- `.github/workflows/build.yml` — тесты, сборка APK и публикация релиза `latest` при каждом push.

Подпись APK: ключ `app/pitouch.keystore` (пароль `pitouch`) лежит в репозитории специально,
чтобы новые сборки ставились поверх старых. Для публикации в магазинах замените его.
