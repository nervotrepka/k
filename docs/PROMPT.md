# ТЗ: телефон как Bluetooth-тачпад и клавиатура для Raspberry Pi

> Согласованное ТЗ. Ответы на вопросы — в разделе «Решения» в конце.

## Цель
Мобильное приложение, которое превращает телефон в беспроводной тачпад и клавиатуру
для Raspberry Pi. Соединение — только Bluetooth, без Wi-Fi и без интернета.

## Архитектура [?]
**Вариант A (рекомендуемый, только Android 9+):** телефон притворяется стандартным
Bluetooth HID-устройством (клавиатура + мышь) через `BluetoothHidDevice` API.
Raspberry Pi видит его как обычную BT-клавиатуру/мышь:
- на Pi ничего ставить не нужно, сопряжение через стандартное меню Bluetooth;
- работает в любом окружении: рабочий стол (X11/Wayland), консоль, экран входа;
- бонусом работает и с другими устройствами (ПК, ТВ, планшет).

**Вариант B (если нужен iPhone):** приложение по BLE шлёт события маленькому
сервису на Pi (Python, systemd), который создаёт виртуальные устройства через `uinput`.
Требует установки скрипта на Pi, но работает и с iOS.

## Функции

### Тачпад
- Перемещение курсора одним пальцем с ускорением; настраиваемая чувствительность.
- Тап одним пальцем — левый клик, тап двумя — правый клик.
- Двойной тап с удержанием — перетаскивание (drag).
- Вертикальная и горизонтальная прокрутка двумя пальцами.
- Отдельные кнопки ЛКМ / ПКМ внизу экрана (опционально).

### Клавиатура
- Ввод текста через системную клавиатуру телефона (поддержка автокоррекции и голосового ввода).
- Панель спецклавиш: Esc, Tab, Ctrl, Alt, Super, Shift (залипающие модификаторы),
  стрелки, Home/End, PgUp/PgDn, Delete, Backspace, Enter, F1–F12.
- Быстрые сочетания: Ctrl+C / Ctrl+V / Ctrl+Z, Alt+Tab, Ctrl+Alt+T (терминал).
- Медиа-клавиши: громкость, play/pause [?].
- Русский язык [?]: HID передаёт коды клавиш, а не символы, поэтому раскладка
  должна быть включена на Pi; приложение транслирует кириллицу в коды по раскладке ЙЦУКЕН
  и умеет переключать язык (сочетание настраивается).

### Подключение
- Экран со списком сопряжённых устройств, кнопка «подключиться», автопереподключение
  к последнему устройству при запуске.
- Индикатор состояния соединения.
- Экран не гаснет, пока приложение открыто.

### Интерфейс
- Один экран: сверху — тачпад, снизу — панель клавиш, кнопка вызова клавиатуры.
- Тёмная тема, ландшафт и портрет.
- Язык интерфейса: русский.

## Технические требования
- Android: Kotlin + Jetpack Compose, minSdk 28 (Android 9) [?].
- Сборка APK через GitHub Actions — готовый файл скачивается из релиза/артефакта.
- Для варианта B: Python 3 + `bluez`/`bleak`/`python-uinput` на Pi, установщик одной командой.
- Инструкция в README: сопряжение, установка APK, решение типичных проблем.

## Критерии готовности
1. Сопряжение Pi ↔ телефон через стандартное меню Bluetooth на Pi.
2. Курсор двигается плавно, без заметной задержки; клики, drag и скролл работают.
3. Текст на латинице (и кириллице, если нужно) набирается в терминале и браузере на Pi.
4. Сочетания с модификаторами (Ctrl+Alt+T и т.п.) срабатывают.
5. После перезагрузки Pi телефон переподключается одним нажатием или автоматически.

## Решения (по ответам)
- Телефон: Honor 20 (Android 9/10) → основной режим A (Bluetooth HID).
  У Huawei/Honor HID-режим бывает отключён, поэтому реализован и запасной режим B (сервер на Pi).
- Pi: Raspberry Pi 3B+, Raspberry Pi OS; установка сервиса на Pi допустима.
- Кириллица нужна, переключение раскладки — Alt+Shift (настраивается).
- Нужны: кнопки ЛКМ/ПКМ, гироскоп-мышь, жесты тачпада.
- Сборка: APK из GitHub Actions, установка вручную.
- Медиа-клавиши не нужны (не реализованы).

## Версия 2 (дополнения)
- Несколько устройств (Pi, Windows, Android-планшет, Samsung TV) с быстрым переключением и
  сочетанием смены раскладки на каждое устройство.
- Пульт ТВ двумя способами: Bluetooth (consumer-клавиши HID) и Wi-Fi (сетевой протокол Samsung:
  WebSocket 8001/8002 для 2016+, порт 55000 для 2010–2014; серия J 2015 г. — только Bluetooth).
  Кнопки: питание, источник, домой, меню, стрелки, OK, назад, громкость, каналы, медиа, цифры, YouTube.
- Связь сохраняется при сворачивании (foreground-сервис с уведомлением).
- Адаптивная вёрстка: половина экрана, альбомная ориентация, планшет.
- Вкладка «Текст»: набрать на телефоне и отправить в поле ввода (на ТВ по Wi-Fi — целиком).
